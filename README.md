# StudySpace — Smart Study Hub

A responsive, browser-based study productivity web application built with HTML, CSS and vanilla JavaScript.

## Features
- Dashboard with study statistics and daily completion progress
- Task manager with priority, due date, completion, filters and delete
- Notes creator with saved notes and delete
- Flashcards with question/answer flip and next/previous navigation
- Pomodoro focus timer (25-minute focus, 5-minute short break, 15-minute long break)
- Light/dark theme toggle
- Responsive layout for desktop, tablet and mobile
- Local browser storage using `localStorage` (no backend or account required)

## Run the project
1. Extract the ZIP file.
2. Open the `smart-study-hub` folder.
3. Double-click `index.html`, or open it in Chrome, Edge or Firefox.

Optional: use VS Code with the Live Server extension and choose **Open with Live Server**.

## Project structure
- `index.html` — application layout and pages
- `styles.css` — responsive styling and themes
- `app.js` — application logic and local storage

## Notes
This is a front-end university project prototype. Data is stored in the browser on the device where it is used. Clearing browser site data will remove saved tasks, notes, flashcards and focus minutes. A shared multi-user database, login system and cloud synchronization would require a backend.
